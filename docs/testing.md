## 历史性能样本

本机一次受控导入检查包含 29 条可导入会话、17,882 个父子任务事件，总正文约 217 MB。列表 JSON 约 7.8 KB，后续摘要列表读取约 4 ms；首次导入约 5.75 s。再次导入新增 0 条。以上是本机样本，不代表所有机器或所有历史规模的性能保证；临时副本已清理，原历史未修改。

Rust 的 5 项用例覆盖摘要迁移、正文按需读取、记录更新、图片草稿、坏文件隔离和父子历史导入。子任务 get/cancel 的真实响应已核对；不存在的任务会返回明确提示，不能显示虚假的取消成功。

首次连接失败恢复已在隔离桌面程序验证：原需求与 1 张图片被保存，用户在等待连接期间继续输入的新草稿也同时保留，重载后可通过“重新发送”恢复原需求。

真实 Grok 受控子任务管理测试通过：get 返回 initializing 状态，cancel 返回 cancelled=true，主任务正常以 end_turn 结束。

## 输入性能回归（0.2.2）

测试历史包含折叠的 8 MB 工具输出，连续输入 45 次、间隔 60 ms，并等待草稿保存。同机桌面测试中，大对象序列化次数从 12 次降至 0 次；最长动画帧间隔从约 92 ms 降至 9 ms，超过 50 ms 的帧从 4 次降至 0 次。结果是此合成场景的观测值，不代表所有设备与会话。

另外验收了重启恢复、输入后立即切换会话、中文输入法 Enter 不发送，以及模拟 ACP 流式输出期间继续打字。当前自动测试为 34 项前端和 7 项 Rust 用例。
