# 测试范围

版本 0.1.0，Windows，Grok Build 1.0.25。

## 自动测试

`npm test` 包含 21 项用例，覆盖 ACP 消息合并、工具更新、工具文本与导出、队列顺序与暂停、交互回答编码、数学公式解析和图片内容及队列恢复。

## 桌面联调

| 场景 | 检查内容 |
| --- | --- |
| 图片输入 | 将图片内容发送给真实 Grok，正确识别图中文字和数字；刷新后历史图片仍可见 |
| Grok 提问 | 选择选项并补充文字，CLI 收到后继续回答 |
| 计划确认 | CLI 发起计划确认，批准后继续执行 |
| 消息队列 | 顺序执行，待执行需求可编辑或删除，暂停和恢复 |
| 输出中改设置 | 下拉框可操作，下一条需求应用新思考强度与授权模式 |
| 流式公式 | SVM 公式在长回答结束前渲染，未闭合内容保持可见 |
| 历史管理 | 重命名、归档、刷新、恢复，正文与草稿保持一致 |
| 窗口布局 | 1280×800 与最大化，标题栏双击、面板调整 |

## 显示样例

开发测试页采用实际组件，覆盖公式、矩阵、多行对齐、长代码、宽表格、中文、长路径、引用、工具失败和提问表单。内容宽度 460/640/900 与字号 14/18/22 的组合已检查横向溢出。

复制测试核对传入剪贴板接口的内容，没有完成系统剪贴板读回验证。多题、多选、取消和修改计划的全部组合，尚未完成真实 CLI 回归。长会话压力测试、跨平台和多显示器测试也仍待补充。
