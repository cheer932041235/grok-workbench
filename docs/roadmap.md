# 改进方向

[返回首页](../README.md) · [参与贡献](../CONTRIBUTING.md)

以下是工作方向，不是已实现功能或发布日期承诺。

## 优先完善日常使用

- **历史加载与保存**：继续检查超长单条会话、存储空间不足与大量图片的使用体验。
- **长会话阅读**：测量数百轮会话的加载、滚动和持续渲染，再决定分段加载方式。
- **图片体验**：完善 Markdown 导出图片与大图预览。
- **交互回归**：覆盖多题、多选、取消、修改计划等真实 CLI 场景。

## 进一步增强

- 会话正文搜索和项目分组。
- 文件树、只读文件预览及文件路径引用。
- 多显示器、不同 DPI 和 macOS/Linux 验证。
- 评估多会话独立运行，对进程、队列和存储的影响先讨论再实现。

## 适合首次贡献

- 为一个显示问题提供最小 Markdown 示例和对应测试。
- 改善按钮名称、键盘操作或说明文字。
- 补充经过实际操作的安装步骤和故障定位说明。
- 用真实 CLI 验证一个尚未覆盖的交互分支，并记录版本和结果。

开始前可以先在 Issue 中说明准备做的范围。对于尚未明确方案的功能，讨论本身也是有价值的贡献。
