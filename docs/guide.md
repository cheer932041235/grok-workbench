# 使用指南

[返回首页](../README.md)

## 安装与连接

1. 安装并登录 [Grok Build CLI](https://github.com/xai-org/grok-build#installing-the-released-binary)，确认终端中的 `grok --version` 能输出版本。
2. 下载 [Windows 安装包](https://github.com/cheer932041235/grok-workbench/releases/tag/v0.1.0)。缺少 WebView2 时，安装程序需要联网。
3. 启动工作台，选择项目文件夹。CLI 未在 PATH 中时，在“连接与显示设置”填写可执行文件完整路径。

安装版不需要 Node.js 或 Rust。登录、账户和模型访问由 Grok CLI 管理；本应用需要本机 CLI，不能直接用网页 Grok 的登录状态代替。

## 发送和排队

- `Enter` 发送，`Shift+Enter` 换行。
- Grok 回答时继续输入，下一条需求进入队列。
- 待执行需求可编辑、删除、上移。暂停后点击“继续队列”执行。
- 点击停止会中断当前执行并暂停队列。重启恢复的队列也保持暂停。
- 回答期间调整模型、思考强度或授权模式，从下一条需求开始生效。

默认“完全允许”允许 Grok 执行命令和修改文件。需要逐项确认时选择“默认授权”。Grok 主动提问和计划确认会显示为交互卡片，需要提交你的选择或意见。

## 图片与公式

点击“＋ 图片”选择文件，或在输入框粘贴截图。支持 PNG、JPEG、WebP；每条最多 4 张，每张最多 5 MB。发送前可预览和移除，图片会跟随对应需求排队。

已发送图片保存在工作台会话中。已有会话会保存图片草稿；尚未建立会话时，未发送图片暂不跨重启保存。Markdown 导出当前只包含文字，图片请在应用中查看。

公式支持 `\(...\)`、`\[...\]`、`$...$`、`$$...$$`。单个公式收到结束符后排版，不需要等待整轮回答结束。未闭合公式暂时显示源码，代码块中的公式符号保持原样。

## 管理历史

“进行中”显示未归档会话；归档后从这个列表移走，内容和草稿保留。“已归档”中可以查看和恢复。打开归档对话继续发送需求，也会恢复为未归档会话。

每条会话下方有重命名入口。搜索按当前分类中的标题和工作目录匹配，暂不搜索正文。

目前管理的是工作台创建的记录。独立 Grok 终端中的旧对话尚未提供导入入口。

## 阅读与导出

拖动两侧分隔线调整面板宽度；顶部可以调整字号、切换专注模式或只看回答/工具。详细行距设置位于“连接与显示设置”。

代码、公式和表格过宽时在自身区域内滚动。工具卡片可展开查看输出或文件差异。右上角“导出”保存当前会话的 Markdown 文件。

## 常见问题

**找不到 Grok：** 先在终端运行 `grok --version`；在设置中填写实际可执行文件路径，并选择存在的项目目录。

**只能排队，不能同时执行多个对话：** 当前设计是单会话串行执行，多会话并行尚未实现。

**长历史加载较慢：** 列表只读取摘要，选中后加载该会话全文。单个长会话尚未采用虚拟列表。

**历史文件出错：** 损坏记录会单独显示警告，其他记录仍可加载。请保留原记录并报告错误信息。

更多问题请通过 [Issue 模板](https://github.com/cheer932041235/grok-workbench/issues/new/choose) 提供复现步骤。

## 导入原有 Grok 历史

点击侧栏“导入 Grok 历史”。应用读取 GROK_HOME 或默认 Grok 用户目录下的会话，不修改 CLI/TUI 原文件。重复导入会跳过工作台已有的会话，保留你在这里修改的标题、归档状态与草稿。不完整的会话显示具体提示，源会话停止写入后可再次尝试导入。

历史列表只读取标题、目录、时间和归档状态；点击会话后再加载正文与图片。归档只是隐藏到“已归档”，可以随时恢复。

## 查看与管理子任务

Grok 派发子任务后，主对话上方会显示独立卡片。展开查看子任务类型、思考、工具、计划和结果。连接当前会话后可以“刷新状态”或“取消子任务”。历史记录中的任务未必仍存在于当前 Grok 进程，因此不会假定它仍在运行；找不到任务时保留历史内容并显示提示。

首次连接失败的需求保留在新对话的“上次需求尚未发送”区域，可以重新发送。图片和文字草稿也会恢复；该入口不会自动执行任务。

## 点击文件预览

点击回答中的本地 Markdown 链接，或展开工具卡片后点击文件位置、差异路径。右侧显示预览，中间可以继续输入。相对路径按该会话的工作目录解析；预览文档内部的相对文件链接按文档所在目录解析。

- Markdown：阅读视图显示公式与表格，可切换源码。
- 代码与 UTF-8 文本：语法高亮、行号；`src/main.rs:42` 或 `src/main.rs#L42` 跳转指定行。
- PNG、JPEG、GIF、WebP、BMP：图片预览与缩放。
- 拖动左边缘调整宽度；窗口较窄时暂时收起会话列表，关闭预览后恢复。
- 文件更新后点击“刷新”。“系统打开”用于常见文档和图片；代码及脚本可通过“打开文件夹”选择编辑器。

文本上限 2 MB、图片上限 10 MB。较长文本使用纯文本视图，避免高亮阻塞界面。PDF 与 Office 文件目前交给系统应用；HTML 与 SVG 显示源码。文件预览与文件上传是不同功能，此功能不增加通用附件支持。

## 使用对话目录

右侧“对话目录”按顺序列出每一轮用户提问，序号与正文卡片一致。点击摘要跳到对应问题，当前阅读位置高亮。相同的“继续”仍是独立条目；只有图片的消息显示为“图片提问”。

切换到“任务概览”可查看计划和工具统计。窄窗口或专注模式下，使用正文顶部的“目录”按钮打开导航。处于“工具”筛选时，目录跳转会恢复“全部”显示。

点击目录后暂停自动跟随，避免新输出打断阅读；点击输入区上方“回到最新输出”可恢复跟随。
